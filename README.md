# PortSwigger Scripts

A collection of Python scripts developed while solving labs from the **PortSwigger Web Security Academy**. These scripts automate repetitive tasks, simplify vulnerability testing, and demonstrate common web security concepts in a controlled learning environment.

## Objectives

* Automate repetitive tasks encountered during PortSwigger labs.
* Demonstrate practical exploitation techniques.
* Improve Python scripting skills for web application security.
* Build a reusable toolkit for learning and practicing web security.

> More scripts will be added as I complete additional labs.

## Disclaimer

These scripts are intended for educational purposes only and should be used exclusively in authorized environments, such as the PortSwigger Web Security Academy labs.
